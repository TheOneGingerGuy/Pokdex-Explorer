# Pokdex-Explorer
Creating a Pokédex for users to save their pokemon.

Pokedex Explorer.
Cole Anderson, Ben Andrade
A website used to store caught pokemon and view the orginal 151 pokemon in correct pokedex order
We used the Tailwind documentation for the tailwind parts and I used some css for stuff I couldn't figure out in tailwind and I used youtube for explanations of certain abilitys for what we were trying to do and used google to help try to debug issues I was having.
Switch to shiny button if the pokemon caught is shiny and favorite button for your favorite creatures. Scroll to the top button, Animated cards with pokemon stats and abilitys. and saving to local storage pokemon itendification and filter by types
I learned how to fetch api's and get the information I needed from the output of the API and how to input it into my code I also got more familiar with JQuery functions and how tailwind works and how to implement it into code even though I still am not very profcient at it
We plan to improve the way the website looks as it looks very rudimentary at the current moment we also plan to make the search function more seamless.
